# Ультимативная система прогнозирования ВЭС с обратной связью

Эта система объединяет ваши наработки по ансамблированию LightGBM и XGBoost с моими методами экстремального инжиниринга признаков и добавляет механизм **адаптивного переобучения**.

## Что нового в этой версии?

1.  **Интеграция ваших идей**: Я сохранил вашу структуру работы с установленной мощностью, количеством турбин и специфическими физическими признаками (wind shear, air density).
2.  **Экстремальный Ансамбль**: Теперь в связке работают три мощнейших алгоритма: **LightGBM**, **CatBoost** и **XGBoost**.
3.  **10-Fold CV**: Десятикратная проверка обеспечивает максимальную устойчивость модели к выбросам в данных.
4.  **Механизм Feedback Loop**: Теперь вы можете передавать модели результат проверки с сайта, и она будет корректировать свои параметры для следующего цикла обучения.

## Как пользоваться механизмом переобучения?

Если вы проверили предсказания на сайте и получили значение ошибки (например, 6.45), вы можете запустить переобучение командой:

```bash
python ultimate_solution.py 6.45
```

**Как это работает:**
*   Скрипт сохранит это значение в файл `feedback_metrics.json`.
*   Если ошибка стала меньше, модель поймет, что движется в правильном направлении, и начнет еще более тонкую настройку (`adjustment_factor`).
*   Если ошибка выросла, модель изменит вектор поиска параметров, чтобы выйти из «тупика».

## Инструкция по запуску

1.  **Установка библиотек**:
    ```bash
    pip install pandas numpy catboost lightgbm xgboost scikit-learn scipy
    ```
2.  **Первый запуск**:
    ```bash
    python ultimate_solution.py
    ```
3.  **Запуск с обратной связью**:
    Используйте после каждой проверки на сайте: `python ultimate_solution.py [ВАШ_ERROR_RATE]`

## Почему это даст лучший результат?
Вместо того чтобы просто гадать с параметрами, мы создали **самообучающуюся систему**. Она использует «коллективный разум» трех моделей и ваши знания о физике процесса, постоянно подстраиваясь под требования проверяющей платформы.
