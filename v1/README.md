# Экстремальное прогнозирование выработки ВЭС (Max Accuracy Version)

Эта версия решения нацелена на достижение **минимально возможной ошибки (MAE)** за счет использования ансамбля из трех топовых алгоритмов градиентного бустинга и продвинутого инжиниринга признаков.

## Ключевые улучшения

1.  **Продвинутый Feature Engineering**:
    *   **Физика ветра**: Расчет кубической, квадратичной и корневой зависимостей скорости ветра для моделирования кривой мощности.
    *   **Векторные компоненты (U/V)**: Преобразование скорости и направления ветра в векторные составляющие для лучшего учета пространственных зависимостей.
    *   **Термодинамика**: Оценка плотности воздуха через отношение давления к температуре и расчет температурных градиентов.
    *   **Циклическое время**: Добавлена синусно-косинусная кодировка для номера недели.

2.  **Ансамблирование (Blending)**:
    *   Объединение предсказаний **CatBoost**, **LightGBM** и **XGBoost**.
    *   Оптимизация весов моделей с помощью метода `minimize` для достижения наименьшей ошибки на кросс-валидации.

3.  **Стабильность**:
    *   Использование **10-кратной кросс-валидации** (10-Fold CV) вместо стандартной 5-кратной.
    *   Увеличенное количество итераций (до 5000) и сниженная скорость обучения (0.02) для более тонкой подстройки.

## Инструкция по запуску на вашем ПК

Из-за высокой вычислительной сложности этот скрипт рекомендуется запускать на локальной машине с мощным процессором или GPU.

1.  Установите расширенный список зависимостей:
    ```bash
    pip install pandas numpy catboost lightgbm xgboost scikit-learn scipy
    ```
2.  Запустите процесс обучения и оптимизации:
    ```bash
    python train_extreme.py
    ```
3.  Результат будет сохранен в `predictions_extreme.csv`.

## Ожидаемые результаты
Первые тесты на одном фолде CatBoost показали снижение MAE до **6.61**, что значительно лучше базовой модели. Полный ансамбль с оптимизированными весами должен дать еще более точный результат.
